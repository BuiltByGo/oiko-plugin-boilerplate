Oiko plugin boilerplate — secure-by-default WordPress plugin scaffold.

== Description ==

This is the Oiko plugin boilerplate. It is not meant to be installed
as-is on a production site — it's the starting point for a new Oiko
plugin, generated via `npx create-oiko-plugin` or cloned directly.
